# Brand assets

LunarCrush mark and wordmark, pulled from lunarcrush.com (`logo.png`, `apple-touch-icon.png`) and their vector tracings (`mark-white.svg`, `full-white.svg`), used only for the "Made by LunarCrush" credit. The extension's own icon lives in `icons/icon.svg`. These are trademarks of LunarCrush, Inc.; they are in this repository so the icons and store tiles can be rebuilt, and they are not covered by the MIT license.

Fonts: Plus Jakarta Sans ships with the popup under the SIL OFL (`popup/fonts/`). Butler, used only in the store tiles, is fetched at render time into `_fetched/` (gitignored) and is not redistributed here.
